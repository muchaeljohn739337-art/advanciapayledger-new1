## 🌐 DEPLOYMENT OPTIONS

### Option 1: DigitalOcean App Platform (Recommended)

#### Step 1: Install doctl CLI
```bash
# Windows (PowerShell - Run as Administrator)
Set-ExecutionPolicy Bypass -Scope Process -Force
[System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072,192, -bor 768, -bor 240, -bor 196, -bor 128, -bor 27, -bor 14
Invoke-WebRequest -Uri "https://dl.cloudsmith.io/public/digitalocean/cli/doctl-1.100.0-windows-amd64.exe" -OutFile "doctl.exe"
.\doctl.exe version
```

#### Step 2: Authenticate
```bash
.\doctl.exe auth init
# Follow prompts to enter your DigitalOcean API token
```

#### Step 3: Deploy
```bash
.\deploy-digitalocean.sh
```

### Option 2: DigitalOcean Droplet (Manual)

#### Step 1: Create Droplet
- Go to DigitalOcean dashboard
- Create new Droplet
- Choose: Ubuntu 22.04 LTS
- Size: Basic (2 GB RAM, 1 CPU, 50 GB SSD)
- Region: New York 3 (or closest to you)

#### Step 2: Setup Server
```bash
# SSH into your droplet
ssh root@your-droplet-ip

# Update system
apt update && apt upgrade -y

# Install Node.js 18
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
apt-get install -y nodejs

# Install Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh

# Install Git
apt-get install -y git

# Clone repository
git clone https://github.com/advancia-devuser/advanciapayledger-new.git
cd advanciapayledger-new/backend-clean

# Build and run
npm install
npm run build
docker build -t advancia-payledger .
docker run -d -p 4000:4000 --name advancia advancia-payledger
```

#### Step 3: Setup Domain (Optional)
```bash
# Install Nginx
apt-get install -y nginx

# Configure Nginx
cat > /etc/nginx/sites-available/advanciapayledger << EOF
server {
    listen 80;
    server_name advanciapayledger.com;

    location / {
        proxy_pass http://localhost:4000;
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
        proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto \$scheme;
    }
}
EOF

# Enable site
ln -s /etc/nginx/sites-available/advanciapayledger /etc/nginx/sites-enabled/
nginx -t
systemctl restart nginx
```
